SFC to CD144 Converter

Convert an AERMET surface output (.SFC) file to CD144 format (.met). The SFC file must contain hourly data already in local standard time (as produced by AERMET Stage 3).

Ceiling height is left blank because SFC files only carry total cloud cover, not individual layer heights.
